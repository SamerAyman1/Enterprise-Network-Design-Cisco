# Enterprise-Network-Design-Cisco

Enterprise Network Design & Security Implementation
Project Overview
A comprehensive simulation of a corporate network infrastructure using Cisco Packet Tracer. The project demonstrates the design and configuration of a scalable network for a company with four main departments: Sales, Marketing, HR, and Customer Service.  

Key Technical Features
Layer 2 & Layer 3 Switching: Implementing a hierarchical model with Access, Distribution, and Core layers.  

VLAN Management: Configured department-specific VLANs with centralized management using VTP (VLAN Trunking Protocol).  

Redundancy & Performance: Optimized network convergence using Rapid Spanning Tree Protocol (RSTP) and increased bandwidth through EtherChannel (LACP/PAgP).  

Network Security: Hardened the infrastructure by implementing Port Security, BPDU Guard, and PortFast for end-user ports.  

Automated Addressing: (Optional) Implementation of a DHCP Server for dynamic IP allocation across different VLANs.  

Topology Details
Departments: 4 Main Departments.  

VLANs: 8 Total VLANs (2 per department).  

Protocols Used: VTP, RSTP, Trunking (802.1Q), EtherChannel, Port Security.  

Tools Used
Cisco Packet Tracer.
